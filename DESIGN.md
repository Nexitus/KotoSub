# KotoSub UI design

KotoSub is an operational tool for translating video and managing local models. Keep controls direct, labels clear, and the existing dense workflow easy to scan. Preserve the project's semantic colors, Inter typography, spacing, and shared form components in `frontend/index.css` and `frontend/components/ui/`.

The closest VoltAgent reference is [ElevenLabs](https://github.com/VoltAgent/awesome-design-md/tree/main/design-md/elevenlabs), an AI audio product. Apply its emphasis on focused controls and readable hierarchy. Keep KotoSub's established purple brand tokens and compact utility layout; do not copy ElevenLabs branding, typography, gradients, or marketing presentation.

Use native labeled controls where possible. Model selectors should list only models exposed by the backend, preserve keyboard operation, and clearly show installed or missing status. Respect the existing light and dark themes and reduced-motion preference.
